# Xavfsizlik

- API kalit va sozlamalar ilova xotirasida saqlanadi. Kalitni kodga yoki GitHub'ga yozmang.
- Maxsus imkoniyatlar (Accessibility) va "ilovalar ustida ko'rsatish" kuchli ruxsatlar. Faqat o'zingiz ishongan APK'ni o'rnating.
- Zaiflik topsangiz, ommaviy issue ochmasdan, repozitoriy egasiga shaxsiy xabar (GitHub Security Advisories) yuboring.
