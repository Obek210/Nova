# Hissa qo'shish

1. Fork qiling, `feature/nom` nomli shox oching.
2. Yangi buyruq: `Commands.kt` o'rniga `Nova.kt` dagi `Commands.tryHandle` ichiga shart qo'shing; murakkab ishlar `Extras.kt` ga.
3. `gradle assembleDebug` xatosiz o'tishi kerak (GitHub Actions ham tekshiradi).
4. Pull request'da nima qo'shilganini va qaysi Android versiyada sinaganingizni yozing.
